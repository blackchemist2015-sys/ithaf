# الرسومات التنفيذية للتصميم (أ) — مزولة الشاخص القطبي

مبنية على اللوحتين A-01 وA-02: وجه رخام دائري Ø12.70 م، وحلقة تقويم جرانيت إلى Ø14.50 م، وشاخص 316L سمك 30 مم عقدته على ارتفاع 2.400 م فوق (0, +0.550).

| الملف | المحتوى |
|---|---|
| `A_Execution_Drawings_A1.pdf` | X-00 الغلاف، X-01 التوقيع، X-02 تقسيم البلاط والحلقة، X-03 الحفر والتطعيم، X-04 القطاعات والأساس، X-05 تصنيع الشاخص، X-06 التسلسل والمعايرة ونقاط التوقف، X-07 الكميات |
| `A_Model_1to15_A1.pdf` | M-01 النموذج 1:15، M-04 بروتوكول الاختبار والقراءات المتوقعة (نوفمبر–ديسمبر 2026) |
| `pdf/M-02.pdf` | قالب وجه النموذج بالحجم الطبيعي 1050 × 1050 مم (طباعة UV أو راسمة 42 بوصة) |
